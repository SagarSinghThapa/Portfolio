# Orchest — Data Science Workflow Platform

**Problem:**

Data-science workflows often require multiple interconnected steps for data ingestion, preprocessing, analysis, model development, and evaluation, making experimentation difficult to organize and reproduce when handled as disconnected scripts or notebooks.

**Solution:**

Built a structured data-science workflow using Orchest to organize and execute interconnected data-processing and machine-learning tasks as a reproducible pipeline, enabling individual components to be developed, executed, and monitored within a unified workflow.

**Technologies:**

Python, Orchest, Pandas, NumPy, Scikit-Learn, Jupyter, Data Pipelines, Machine Learning

**Your Contribution:**

* Designed the end-to-end Orchest pipeline by breaking the data-science workflow into modular, connected processing stages.
* Implemented Python-based data preprocessing, transformation, analysis, and machine-learning components within the pipeline.
* Connected pipeline steps to pass processed data between stages and structured the workflow for repeatable experimentation.
* Evaluated intermediate outputs and model results to identify data-processing and modelling issues during development.

**Results:**

* Created a modular and reproducible ML workflow instead of running individual data-processing and modelling scripts independently.
* Demonstrated an end-to-end pipeline covering data preparation, analysis, model development, and evaluation.
* Improved workflow organization by separating individual tasks into reusable pipeline stages.
