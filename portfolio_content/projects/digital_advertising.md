# Digital Advertising Campaign Analytics

**Problem:**

Digital advertising campaigns generate large volumes of telemetry across platforms, making it difficult to consolidate campaign data, evaluate performance consistently, identify abnormal behavior, segment campaigns, and convert ML outputs into actionable optimization decisions.

**Solution:**

Developed an end-to-end AI-powered analytics platform that processes campaign data through multiple machine-learning workflows. The system performs predictive analytics, anomaly detection, and K-Means clustering, exposes analytics through backend APIs, and uses Google Gemini API to transform model outputs into structured, natural-language campaign recommendations and insights.

**Technologies:**

Python, Pandas, NumPy, Scikit-Learn, FastAPI, Next.js, React.js, MongoDB Atlas, Google Gemini API, Tailwind CSS, REST APIs, Git/GitHub

**Your Contribution:**

* Performed data preparation and feature engineering required for model training and evaluation.
* Integrated model outputs with the Google Gemini API to generate context-aware campaign optimization recommendations.
* Contributed to the FastAPI backend and integrated analytics workflows with the Next.js/React dashboard.

**Results:**

* Delivered an integrated workflow covering campaign data preparation → ML analysis → API-based inference → AI-generated recommendations → dashboard visualization.
* Implemented three complementary analytics workflows: supervised prediction, anomaly detection, and K-Means clustering.
* Enabled campaign insights to be presented as structured, natural-language recommendations rather than raw model outputs.
